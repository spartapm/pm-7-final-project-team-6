# 캐릿 Careet — 6조

내배캠 PM 7기 6조. [캐릿](https://www.careet.net/)에 **아티클 → 나의 투두** 실행 레이어를 붙인 데스크톱 웹입니다.

화면은 [피그마 와이어프레임](https://www.figma.com/design/ospI5a1piezDSe4gY3Z90P/판타스틱-포?node-id=475-414)과 [디자인 가이드](https://www.figma.com/design/ospI5a1piezDSe4gY3Z90P/판타스틱-포?node-id=281-4233)를 기준으로 맞췄습니다.

`docs/`의 ONE&BEAUTY 기획서는 1조 제품과 같은 문서입니다. 이 폴더의 구현은 캐릿 웹(투두)입니다.

## 실행

```bash
npm install
npm run db:schema   # 최초 1회, Supabase 테이블 생성
npm run dev
```

브라우저에서 http://localhost:3006  
1920×1080 데스크톱 폭으로 보는 것이 가장 가깝습니다. 최소 폭 1180px.

`.env.local`은 git에 올리지 않습니다. DB password / service role은 `NEXT_PUBLIC_`에 넣지 마세요.

## 로그인 · 세션

비밀번호는 SHA-256으로 저장됩니다. 같은 이메일의 두 번째 로그인부터는 처음 쓴 비밀번호와 같아야 합니다.

- 데모(유저) 계정: `careet@example.com` / `demo`
- 에디터 계정: `editor@careet.com` / `editor` — 아티클 작성·발행·삭제. 일반 유저 메뉴에는 작성이 보이지 않습니다
- 새 이메일로 로그인하면 그 비밀번호로 가입됩니다
- 세션은 브라우저에 30일 동안 유지되고, 같은 이메일이면 Supabase 계정에 투두·노트·발행글·멤버십이 따라갑니다
- 로그아웃은 로컬 세션만 지웁니다. 회원 탈퇴는 클라우드 계정까지 삭제합니다
- 투두 담기·북마크·밑줄 노트·발행·레터·쿠폰은 로그인 후 가능합니다

## 플로우

1. **홈** — 헤더에 나의 투두 N/M 라임 게이지(비로그인 시 로그인 버튼), 히어로(책없쾌), 최신 콘텐츠. **콘텐츠 보기**로 카테고리 필터, 카드 북마크
2. **GNB** — 캐릿 소개, 요즘어 사전, 뉴스클리핑, 이슈 캘린더, 마이크로 트렌드 전광판
3. **검색** — 서브내비 검색 → `/search?q=`
4. **아티클 상세** — 목차·본문, 인용구 **밑줄 노트에 담기**, 우측 맨 위 / 가(글자 크기) / 연필(선택 문장 또는 입력) / 북마크 / 공유, 투두가 있으면 FAB/패널. 커리어 다이어트는 투두 없는 엣지 케이스
5. **나의 페이지 `/me`** — 읽은 / 저장한 / 나의 투두 / 밑줄 노트 탭, 투두 완료·수정·삭제 확인, 빈 상태
6. **내 정보 수정 `/me/edit`** — 이름·이메일·직무, 회원 탈퇴
7. **멤버십 `/membership` · 쿠폰 `/coupons` · 포인트 `/points`** — 2,000P 또는 `PLUS30`으로 플러스, `CAREET10` / `TREND2026` 등록, 출석 100P
8. **트렌드 레터** — 서브내비에서 이메일 구독(첫 구독 50P)
9. **백오피스 `/admin/write`** — 썸네일 필수(10MB, JPG/PNG/WEBP), 판별기준 3개 충족 전 투두 잠금, 투두 50자, 발행 알럿 체인, 보관함 모달, 마지막 저장 시각. 작성 화면 재진입 시 자동 복원은 하지 않고 보관함에서만 불러옵니다.
