# 캐릿 Careet — 6조

내배캠 PM 7기 6조. [캐릿](https://www.careet.net/)에 **아티클 → 나의 투두** 실행 레이어를 붙인 데스크톱 웹입니다.

화면은 [피그마 와이어프레임](https://www.figma.com/design/ospI5a1piezDSe4gY3Z90P/판타스틱-포?node-id=475-414)과 [디자인 가이드](https://www.figma.com/design/ospI5a1piezDSe4gY3Z90P/판타스틱-포?node-id=281-4233)를 기준으로 맞췄습니다.

`docs/`의 ONE&BEAUTY 기획서는 1조 제품과 같은 문서입니다. 이 폴더의 구현은 캐릿 웹(투두)입니다.

## 실행

```bash
npm install
npm run db:schema   # 최초 1회, Supabase 테이블 생성
npm run dev
```

브라우저에서 http://localhost:3006  
1920×1080 데스크톱 폭으로 보는 것이 가장 가깝습니다. 최소 폭 1180px.

`.env.local`은 git에 올리지 않습니다. DB password / service role은 `NEXT_PUBLIC_`에 넣지 마세요.

## 로그인 · 세션

데모는 아무 비밀번호나 됩니다. 세션은 브라우저에 30일 동안 유지되고, 같은 이메일이면 Supabase 계정에 투두·노트·발행글이 따라갑니다.

- 데모 계정: `careet@example.com` / 이름 `김캐릿` (시드 투두·읽음·저장이 있습니다)
- 새 이메일로 로그인하면 빈 계정으로 시작합니다
- 로그아웃은 로컬 세션만 지웁니다. 회원 탈퇴는 클라우드 계정까지 삭제합니다
- 투두 담기·북마크·밑줄 노트·발행은 로그인 후 가능합니다

## 플로우

1. **홈** — 헤더에 나의 투두 N/M 라임 게이지(비로그인 시 로그인 버튼), 히어로(책없쾌), 최신 콘텐츠 3장 + 발행한 글
2. **검색** — 서브내비 검색 → `/search?q=`
3. **아티클 상세** — 목차·본문, 인용구 **밑줄 노트에 담기**, 우측 북마크/공유/맨 위, 투두가 있으면 FAB/패널(담기 → 저장 완료! → 나의 투두로 가기). 커리어 다이어트는 투두 없는 엣지 케이스
4. **나의 페이지 `/me`** — 읽은 / 저장한 / 나의 투두 / 밑줄 노트 탭, 투두 완료·수정·삭제 확인, 빈 상태
5. **내 정보 수정 `/me/edit`** — 이름·이메일·직무, 회원 탈퇴
6. **백오피스 `/admin/write`** — 썸네일 필수(10MB, JPG/PNG/WEBP), 판별기준 3개 충족 전 투두 잠금, 투두 50자, 발행 알럿 체인, 보관함 모달, 마지막 저장 시각. 작성 화면 재진입 시 자동 복원은 하지 않고 보관함에서만 불러옵니다

하드코딩(MVP 범위 밖): GNB 중 캐릿 소개 외, 콘텐츠 보기 드롭다운, 트렌드 레터, 멤버십/쿠폰/포인트. 홈 카드의 북마크 아이콘은 장식이고, 아티클 레일 북마크가 동작합니다.
